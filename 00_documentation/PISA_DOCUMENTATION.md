# PISA questionnaires and codebook

Official source: [OECD PISA 2025 database](https://www.oecd.org/en/data/datasets/pisa-2025-database.html).

The student questionnaire, school questionnaire, and PISA2025_Codebook.xlsx are stored directly in this directory. All 3 were downloaded and verified on 2026-11-14; each matches the previously stored file byte for byte. Exact download URLs, sizes, and SHA-256 hashes are in `pisa_documentation_sources.json`.

The codebook covers student, school, teacher, cognitive-item, and questionnaire-timing files. Other previously collected questionnaires remain here; their provenance was not reverified in this pass.

PDFs and spreadsheets remain local and Git-ignored. The source manifest is tracked so these documents can be retrieved on another machine. No pupil data are downloaded by this documentation step.
